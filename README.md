# GrowthPulse — сайт маркетингової агенції

Практична робота № 3 «Верстка вебсайту засобами HTML і CSS».
Виконала: Гумен Олеся, група 4-18 ФМТП.

Адаптивний багатосторінковий сайт за прототипом і дизайн-системою з Figma (ПР № 2).

## Сторінки
| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `cases.html` | Кейси (портфоліо з фільтрами) |
| `brief.html` | Бриф (форма з 4 кроків) |
| `consultation.html` | Консультація (календар бронювання) |
| `blog.html` | Блог |
| `404.html` | Помилка на сайті |

## Структура стилів
`css/main.css` підключає файли в порядку каскаду:
`tokens.css` (змінні з Figma) → `base.css` → `layout.css` → `components.css` → `utilities.css`.

## Запуск
Збирання не потрібне: відкрийте `index.html` у браузері
або увімкніть GitHub Pages (Settings → Pages → Branch: main / root).

- CSS: W3C CSS Validator (CSS level 3 + SVG) — помилок не знайдено
